## Selected systems

- **[win11-storage-governance-kit](https://github.com/Nongfsq/win11-storage-governance-kit)** —
  Risk-classified Windows 11 storage policy: inspect first, migrate recurring
  growth, and keep system stores on supported maintenance paths.
- **[uac-maintenance-tray](https://github.com/Nongfsq/uac-maintenance-tray)** —
  Bounded UAC maintenance with ownership checks, timed restoration, and a manual
  recovery path.
- **[usb-debug-guard](https://github.com/Nongfsq/usb-debug-guard)** —
  Root-only Android display protection that keeps ADB reachable, restores prior
  settings, and stops on privilege failure.
- **[mac-remote-workstation](https://github.com/Nongfsq/mac-remote-workstation)** —
  Native macOS power policy for closed-lid remote work, backed by snapshots,
  verification, and rollback.
- **[clarity_lazyvim](https://github.com/Nongfsq/clarity_lazyvim)** —
  Colorblind-first Neovim with a small, auditable plugin surface and
  machine-checkable recovery tools.
