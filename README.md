## Public work

| Project | What it does | Stack |
| --- | --- | --- |
| [win11-storage-governance-kit](https://github.com/Nongfsq/win11-storage-governance-kit) | Safe Windows 11 C-drive cleanup, storage migration, and cache governance as reusable Codex Skills. | Python · PowerShell |
| [usb-debug-guard](https://github.com/Nongfsq/usb-debug-guard) | Root-only Android screen protection for long USB debugging sessions. | Kotlin · Jetpack Compose |
| [clarity_lazyvim](https://github.com/Nongfsq/clarity_lazyvim) | Colorblind-first, high-contrast Neovim built on LazyVim. | Lua · Neovim |
| [uac-maintenance-tray](https://github.com/Nongfsq/uac-maintenance-tray) | Temporary UAC maintenance with automatic restoration and multilingual controls. | C# · Windows |
| [mac-remote-workstation](https://github.com/Nongfsq/mac-remote-workstation) | Keeps a plugged-in MacBook remotely reachable while the lid is closed. | Swift · macOS |
| [samsung-t-series-console](https://github.com/Nongfsq/samsung-t-series-console) | Repairs common Samsung T-series SSD issues and handles safe eject. | PowerShell · Windows |
| [otp-bridge](https://github.com/Nongfsq/otp-bridge) | Hands iPhone SMS codes to Windows through a private ntfy channel. | C# · iOS Shortcuts |
| [HdrGuard](https://github.com/Nongfsq/HdrGuard) | Disables HDR during RustDesk sessions and restores it afterward. | C# · Windows |
| [pi-monitor](https://github.com/Nongfsq/pi-monitor) | Monitors a website from Raspberry Pi with RGB status and a small web UI. | Python · Raspberry Pi |
| [zsh_config](https://github.com/Nongfsq/zsh_config) | A portable, recoverable Zsh environment. | Shell · Zsh |
