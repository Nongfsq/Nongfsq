## Command Center

I use GitHub as a remote cockpit for small durable systems: private products, personal automation, readable development environments, research tooling, and focused public projects.

## Operating Principles

- Keep private systems quiet until they are ready to be useful.
- Use topics as the remote filing system.
- Prefer small, durable tools that can be reopened months later.
- Make the development environment part of the product surface.
